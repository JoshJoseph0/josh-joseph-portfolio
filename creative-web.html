The starting point

AI workflow tools can feel technical before you’ve even tried an idea. I’m exploring how visual building blocks and plain language could make experimentation easier to get into.

One loop to build around

Build, Test, Observe, Change and Re-run. A user would change instructions or behaviours, try a simulated situation and compare what happened. The project would configure an existing model; it would not train a new one.

What needs working out

The useful question is what someone learns from each test. I’m considering how to explain differences in responses and how to keep that explanation understandable without hiding important uncertainty.

Where it stands

The project is at the concept stage. Next, I’d prototype one complete test-and-compare flow before exploring saved configurations or sharing.
